# 内在地形 · 微信公众号头像

## 设计含义

- 四层偏心、不规则的等高线：日常经历逐渐形成的个人内在地形，也对应产品的四层记忆。
- 中央暖色石子：一件被听见、被正确记住的小事。
- 深墨蓝与暖琥珀：延续现有产品的安静、克制与温度，不使用常见机器人、对话框或爱心符号。

## 文件

- `inner-terrain-avatar.svg`：1024 × 1024 矢量母版，可继续编辑与无限缩放。
- `inner-terrain-avatar-1024.png`：微信公众号后台上传版。
- `inner-terrain-avatar-256.png`：小尺寸检查与快速预览版。

## 配色

- 深墨蓝：`#081117` / `#14242C`
- 象牙白：`#FFF4E3`
- 暖琥珀：`#F6B866` / `#D9783D`

图形主体保留在中央安全区内，适配圆形头像裁切；头像中不放文字，避免小尺寸下失去辨识度。
